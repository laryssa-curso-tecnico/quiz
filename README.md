# ❓Quiz

Um quiz interativo com perguntas e alternativas, permitindo que o usuário responda às questões e confira seu desempenho ao final.

## Funcionalidades

- Exibição de perguntas e alternativas
- Seleção de respostas
- Verificação das respostas
- Exibição do resultado final

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
